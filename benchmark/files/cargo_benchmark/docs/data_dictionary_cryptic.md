# Data dictionary: cryptic schema

What every table and column of the cryptic schema means. Generated by `scripts/make_dictionary.py` from `schema/descriptions.json`; do not edit by hand.

Give it to a model with `python evaluation/run_ollama.py --variant cryptic --dictionary`. The model then sees each meaning as a comment in the schema.
